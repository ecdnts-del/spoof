iOS Chrome Save-to-Drive UI Spoofing PoC (Hardened)

PoC ini mendemonstrasikan injeksi tag BEGIN_BOLD / END_BOLD melalui manipulasi header Content-Disposition pada unduhan file.

Langkah Pengujian:

  1. Pastikan Anda menggunakan perangkat iOS dan masuk ke akun Google di profil reguler (bukan Mode Penyamaran).
  2. Ketuk tombol unduh di bawah ini untuk memicu unduhan file payload.
  3. Ketuk tombol Download / Save pada bar unduhan di bagian bawah layar.
  4. Amati lembar dialog Account Picker yang muncul.
