⚠️ Advanced Origin & Dialog Spoofing PoC

Simulasi pengujian kerentanan dialog modal lintas asal dengan teknik injeksi waktu berlapis untuk menganalisis efektivitas fungsi mitigasi navigasi.

Analisis Mekanisme Target:
Payload mengarahkan jendela utama ke domain sasaran (misal: google.com) menggunakan referensi _top, lalu mencoba menjadwalkan eksekusi dialog pada celah transisi muat halaman.

Instruksi Pengujian Lab:

  1. Klik tombol di bawah untuk memicu urutan navigasi otomatis.
  2. Amati apakah dialog prompt berhasil disisipkan di atas domain target atau langsung dibersihkan oleh sistem.
