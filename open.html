⚠️ iOS Dialog Spoofing PoC (Enhanced)

Simulasi pengujian kerentanan penundaan dialog modal JavaScript terhadap patch ClearDialogs() pada navigasi.

Mekanisme Patch (Gerrit 3954143):
Browser menutup otomatis semua dialog aktif saat OnNavigationStarted dipicu. PoC ini menguji variasi waktu timing untuk melihat apakah dialog dapat lolos dari pembersihan.

Langkah Uji Lab:

  1. Klik tombol simulasi di bawah.
  2. Skrip akan mengalihkan ke target eksternal sambil mencoba memicu dialog setelah jeda waktu tertentu.
  3. Amati apakah dialog langsung tertutup secara otomatis (ter-mitigasi) atau berhasil muncul di atas domain target.
